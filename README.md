# Project 3 - Power BI Dashboard (Olist Brazilian E-Commerce, Kaggle)

**Dataset:** *Brazilian E-Commerce Public Dataset by Olist* (`olistbr/brazilian-ecommerce` on Kaggle) - ~100,000 real
orders (2016-2018), 9 relational tables: orders, items, payments, reviews, customers, sellers, products, geolocation
(1M rows) and category translation. It is a classic "complex, multi-table" dataset ideal for a star-schema model.

> **Honest note:** a Power BI report (`.pbix`) can only be created inside **Power BI Desktop**, which is a Windows-only app
> and cannot be generated by code. So this project gives you everything *except* the final click-building:
> (1) automated data download + cleaning into a ready star-schema, (2) copy-paste Power Query code,
> (3) 40+ copy-paste DAX measures, (4) a theme file, (5) page-by-page build instructions with exact fields.
> Building the 4 pages takes ~60-90 minutes following the guide. (Mac users: run Windows in a VM, or use Power BI Service in the browser - limited authoring.)

```
powerbi-olist-dashboard/
├── requirements.txt
├── scripts/
│   ├── download_data.py         # Kaggle download (or download manually)
│   ├── make_demo_data.py        # fake data in the same format (offline testing)
│   ├── prepare_data.py          # raw CSVs -> 10 clean star-schema CSVs in data/processed
│   └── generate_powerquery.py   # regenerates powerbi/power_query_all_tables.m
├── powerbi/
│   ├── power_query_all_tables.m # M code for each table
│   ├── data_model.md            # relationships to create
│   ├── dax_measures.dax         # all measures + calculated columns
│   ├── dashboard_layout.md      # 4 pages, visual by visual
│   └── theme.json               # dark-teal theme
└── data/raw, data/processed     # (demo data is included so you can start immediately)
```

## 1. Install (one time)
1. **Power BI Desktop** (free): Microsoft Store -> search "Power BI Desktop", or https://powerbi.microsoft.com/desktop
2. **Python 3.9+**: https://www.python.org/downloads (tick "Add Python to PATH")
3. In a terminal inside this folder: `pip install -r requirements.txt`

## 2. Get the data
**Option A - real Kaggle data (recommended)**
1. Create a free account at kaggle.com. Open https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. *Easiest:* click **Download** -> unzip the 9 CSVs into `data/raw/` (overwrite the demo files).
3. *Or automated:* Kaggle -> your profile -> Settings -> **API -> Create New Token**, save the file `kaggle.json` to
   `C:\Users\<you>\.kaggle\` (Mac/Linux: `~/.kaggle/`), then run `python scripts/download_data.py`.
   (If your Kaggle page shows the newer access-token style, set the environment variable `KAGGLE_API_TOKEN` as Kaggle instructs.)

**Option B - fake demo data**: `python scripts/make_demo_data.py` (a small demo set is already in `data/`).

## 3. Clean and model the data
```bash
python scripts/prepare_data.py
```
Creates in `data/processed/`: `fact_orders, fact_order_items, fact_payments, fact_reviews, dim_customers, dim_products,
dim_sellers, dim_date, dim_state, dim_geo` (.csv). What it does: joins category translations, builds delivery-time/late-flag
columns, aggregates 1M geolocation rows to one row per ZIP prefix, builds a date table and Brazilian state/region lookup.

## 4. Build the dashboard in Power BI Desktop
1. Open Power BI Desktop -> blank report.
2. **Home -> Transform data -> Manage Parameters -> New**: Name `DataFolder`, Type Text, value = full path of
   `data\processed\` **ending with a backslash**.
3. For each block in `powerbi/power_query_all_tables.m`: Home -> New Source -> **Blank Query** -> **Advanced Editor** -> paste the
   block -> Done -> rename the query to the table name (e.g. `fact_orders`). Repeat for all 10. Then **Close & Apply**.
   *(Shortcut: Get Data -> Text/CSV for each file also works; the M code just sets correct types.)*
4. Follow `powerbi/data_model.md` (relationships, date table, sort-by columns).
5. Create measures from `powerbi/dax_measures.dax`.
6. View -> Themes -> Browse for themes -> `powerbi/theme.json`.
7. Build the 4 pages following `powerbi/dashboard_layout.md`.
8. Save as `.pbix` (File -> Save).

## 5. What insights the dashboard answers
* Revenue trend, YoY/MoM growth, and which Brazilian regions/states drive sales.
* Which product categories/sellers make most revenue (Pareto / Top-N).
* How delivery delays hurt customer reviews (on-time vs late review score).
* Payment behaviour (credit card, boleto, installments).

## Troubleshooting
| Problem | Fix |
|---|---|
| `Missing ...olist_orders_dataset.csv` | unzip the Kaggle files into `data/raw/` (names must be unchanged) |
| Kaggle 401/403 | token missing or dataset terms not accepted - open the dataset page once while logged in |
| Power Query: "DataFolder not found" | create the parameter (step 4.2), name is case-sensitive |
| Numbers show as text / wrong dates | re-paste the M block (it sets types with `en-US` culture) |
| Visuals blank after slicing by category | expected for order-level measures (Late Delivery %) - these are on `fact_orders`, which products do not filter |
| Map shows wrong places | set `dim_state[map_location]` data category = "State or Province" |
